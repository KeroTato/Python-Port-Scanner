# 🔍 Python Port Scanner

A simple Port Scanner written in Python using the Socket module.

## 📖 About

This project was created while learning Python for Cybersecurity.
It scans a target IP address, identifies open ports, and attempts to detect the common service running on each open port.

## ✨ Features

- 🎯 Scan a target IP address
- 🔢 Scan a custom port range
- 📡 Detect open TCP ports
- 🌐 Display common service names
- 📊 Show the total number of open ports

## 🛠️ Technologies

- Python 3
- Socket Module

## 🚀 How to Run

python port_scanner.py
